SwiftUI iOS 26 Showcase は、16 個の小さな SwiftUI 画面をまとめた Swift パッケージです。各画面は iOS 26 と macOS 26 で新しく追加された API のグループを 1 つずつ扱います。Liquid Glass、新しいバーとスクロールのモディファイア、リッチテキスト編集、ネイティブの Web ビュー、3D チャート、SF Symbol の描画エフェクト、`@Animatable` マクロ、そしてデバイス上で動作する Foundation Models フレームワークです。どの画面にも API のオプションを試すためのコントロールがあり、使っている SDK のシンボルが一覧で表示されます。自分のアプリで使う前に、これらの API が実際に動く様子を確かめたい開発者に向けたパッケージです。ギャラリー全体を動かすことも、1 つの画面だけを自分のアプリに組み込むこともできます。

## 主な特長

- **6 カテゴリ、16 個のデモ**：Liquid Glass、バーとナビゲーション、スクロールとレイアウト、テキストと Web、チャートとシンボル、Apple Intelligence。そのうち 14 個は macOS でも動作します。
- **検索できるギャラリー**：`ShowcaseGallery` は現在のプラットフォームで使えるデモを一覧表示し、タイトル、概要、API 名を対象に検索できます。
- **1 画面だけでも使える**：`ShowcaseDemoView(.chart3D)` で、1 つのデモを自分のナビゲーションに組み込めます。
- **macOS と iOS Simulator でテスト**：Swift Testing のテストスイートが、カタログ、ヘルパー型、下のデモ一覧表がコードと一致していることを確認します。描画テストは、`ImageRenderer` が描画できる範囲で、各デモが概要と API 一覧以上のものを描画していることを確認します。`List` ベースの 2 つのデモは対象外で、**WebView** のデモではアドレスバーとステータスバーは確認できますが、`WebView` 自体は確認できません。
- **サンプルアプリ**：[Examples/ShowcaseApp](Examples/ShowcaseApp) にある iOS / macOS アプリで、起動引数から任意のデモを開けます。

## クイックスタート

**1. パッケージを追加する**

Xcode で **File › Add Package Dependencies…** を選び、リポジトリの URL を入力します。

```text
https://github.com/muhittincamdali/SwiftUI-iOS26-Showcase.git
```

同じダイアログで **Dependency Rule** を **Branch** にし、`main` と入力します（1.0.0 リリースはこれらのデモより前のものです）。**Add Package** をクリックし、**Add to Target** 列でアプリのターゲットを選んで、もう一度 **Add Package** をクリックします。

**2. モジュールをインポートする**

```swift
import SwiftUIiOS26Showcase
```

**3. 使ってみる**

アプリのメインファイル（`@main` が付いたファイルで、新規 Xcode プロジェクトでは `<YourApp>App.swift` という名前です）の内容を次のコードに置き換えます。

```swift
import SwiftUI
import SwiftUIiOS26Showcase

@main
struct DemoApp: App {
    var body: some Scene {
        WindowGroup {
            ShowcaseGallery()
        }
    }
}
```

実行先として iOS 26 の iPhone シミュレータか **My Mac** を選び、**Run**（⌘R）を押します。カテゴリ別にまとめられたデモの一覧が開くので、試したいものを選んでください。パッケージがより新しいプラットフォームを必要としているというエラーが出た場合は、ターゲットの **General** タブで **Minimum Deployments** を iOS 26 と macOS 26 に設定してください。

## インストール

### Swift Package Manager

Xcode で **File › Add Package Dependencies…** を選び、リポジトリの URL を入力します。

```text
https://github.com/muhittincamdali/SwiftUI-iOS26-Showcase.git
```

または `Package.swift` の `dependencies` に追加します。

```swift
dependencies: [
    .package(url: "https://github.com/muhittincamdali/SwiftUI-iOS26-Showcase.git", branch: "main")
],
targets: [
    .target(name: "YourApp", dependencies: [
        .product(name: "SwiftUIiOS26Showcase", package: "SwiftUI-iOS26-Showcase")
    ])
]
```

## 使い方

### ギャラリー全体を表示する

`ShowcaseGallery` は、現在のプラットフォームで使えるすべてのデモを検索可能な一覧で表示するナビゲーションスタックです。`ShowcaseGallery(initialDemo: .chart3D)` を使うと、表示時に指定したデモを開きます。ディープリンクから開く場合などに便利です。

### 1 つのデモを表示する

`ShowcaseDemoView` は 1 つのデモを表示し、ナビゲーションタイトルを設定します。

```swift
struct ChartScreen: View {
    var body: some View {
        NavigationStack {
            ShowcaseDemoView(.chart3D)
        }
    }
}
```

### カタログを検索する

`ShowcaseCatalog` には、ギャラリーの背後にある一覧、検索、グループ化のロジックがまとまっています。クエリのすべての単語がデモのタイトル、概要、API 一覧のいずれかに含まれていれば、そのデモが一致します。大文字と小文字、ダイアクリティカルマークの違いは区別しません。

```swift
let catalog = ShowcaseCatalog(platform: .iOS)
let matches = catalog.demos(matching: "glass button")   // [.glassButtons]
let sections = catalog.sections(matching: "symbol")     // one section: Charts, Symbols & Animation
let demo = catalog.demo(withID: "webView")              // .webView
```

### デモの裏側にあるヘルパーを使う

いくつかのデモの裏側にあるロジックは public で、テストでカバーされています。

```swift
// What the web view demo accepts in its address bar.
WebAddress.url(from: "swift.org")              // https://swift.org
WebAddress.url(from: "javascript:alert(1)")    // nil

// The heights plotted by the 3D chart, always in -1...1.
SurfaceFunction.peak.height(x: 0, z: 0)        // 1.0
```

`RichTextFormatter` は、`AttributedString` の選択部分の太字、斜体、下線、取り消し線を切り替えます。リッチテキストのデモにあるボタンと同じ処理です。

### 個々のデモについての注意

- **Foundation Models** には Apple Intelligence が必要です。対応していないデバイス、機能がオフの場合、またはモデルのダウンロード中は、デモがどの状態に当たるかを表示し、プロンプトを送信するボタンを無効にします。
- **タブバーのアクセサリ**：`tabViewBottomAccessory(isEnabled:content:)` には iOS 26.1 が必要です。26.1 以降ではデモがこれを使い、26.0 では `tabViewBottomAccessory(content:)` を付けたり外したりして切り替えます。
- **WebView** は表示時に `https://www.swift.org` を読み込むため、ネットワーク接続が必要です。アドレスバーには `http` と `https` のアドレスしか入力できません。

### サンプルアプリを実行する

`Examples/ShowcaseApp/ShowcaseApp.xcodeproj` を開き、`ShowcaseApp` スキームと iOS 26 のシミュレータまたは **My Mac** を選んで **Run** を押します。このプロジェクトは `project.yml` から [XcodeGen](https://github.com/yonaskolb/XcodeGen) で作成されており、このリポジトリのパッケージをローカルパスで参照しています。

起動引数に `-demo <id>` を渡すと、デモを直接開けます（例：`-demo glassEffect`）。`scripts/screenshots.sh` はこの仕組みを使って `docs/images` の画像を撮影しています。

## アーキテクチャ

このパッケージのライブラリターゲットは `SwiftUIiOS26Showcase` の 1 つだけです。

- `Catalog/`：`ShowcaseDemo` はデモごとに 1 つの case を持ち、メタデータ（タイトル、概要、SF Symbol、カテゴリ、API、プラットフォーム）を保持します。`ShowcaseCatalog` はプラットフォームによる絞り込み、検索、グループ化、デモの検索を担当します。このフォルダのコードは SwiftUI のビューに依存しません。
- `Gallery/`：public なビューである `ShowcaseGallery` と `ShowcaseDemoView`。
- `Demos/<Category>/`：デモごとに 1 つの internal なビュー。ビューを必要としないロジックは、テストでカバーできるよう public なヘルパー型（`WebAddress`、`RichTextFormatter`、`SurfaceFunction`）に置いています。
- `Support/`：`DemoPage`。概要、デモのコントロール、API 一覧を並べる共通レイアウトです。

デモのメタデータは、ギャラリーの行、検索、上の表の唯一の情報源です。README の表とメタデータが食い違うとテストが失敗します。テストは macOS では `swift test`、iOS Simulator では `xcodebuild test` で実行し、CI は両方を実行します。
