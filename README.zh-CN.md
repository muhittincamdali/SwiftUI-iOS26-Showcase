SwiftUI iOS 26 Showcase 是一个 Swift 软件包，包含十六个小型 SwiftUI 界面，每个界面围绕 iOS 26 和 macOS 26 新增的一组 API 构建：Liquid Glass、新的栏和滚动修饰符、富文本编辑、原生网页视图、3D 图表、SF Symbol 绘制效果、`@Animatable` 宏，以及在设备端运行的 Foundation Models 框架。每个界面都提供用于尝试 API 各项选项的控件，并列出它用到的 SDK 符号。它面向希望在自己的应用中使用这些 API 之前先看到它们实际运行效果的开发者：可以运行完整的演示库，也可以把单个界面放进自己的应用。

## 亮点

- **6 个类别中的 16 个演示**：Liquid Glass、栏与导航、滚动与布局、文本与网页、图表与符号，以及 Apple Intelligence。其中 14 个也能在 macOS 上运行。
- **可搜索的演示库**：`ShowcaseGallery` 列出当前平台可用的演示，搜索会匹配标题、摘要和 API 名称。
- **一次一个界面**：`ShowcaseDemoView(.chart3D)` 可以把单个演示放进你自己的导航结构中。
- **在 macOS 和 iOS Simulator 上测试**：Swift Testing 测试套件会检查目录、辅助类型，以及下方的演示表格是否与代码一致。渲染测试会在 `ImageRenderer` 能绘制的范围内，检查每个演示绘制的内容是否多于其摘要和 API 列表：两个基于 `List` 的演示会被跳过；在 **WebView** 演示中，测试能看到地址栏和状态栏，但看不到 `WebView` 本身。
- **示例应用**：[Examples/ShowcaseApp](Examples/ShowcaseApp) 中有一个 iOS 和 macOS 应用，可以通过启动参数打开任意演示。

## 快速开始

**1. 添加软件包**

在 Xcode 中选择 **File › Add Package Dependencies…**，然后输入仓库地址：

```text
https://github.com/muhittincamdali/SwiftUI-iOS26-Showcase.git
```

在同一个对话框中，把 **Dependency Rule** 设为 **Branch** 并输入 `main`（1.0.0 版本早于这些演示）。点击 **Add Package**，在 **Add to Target** 一栏中选择你的应用 target，然后再次点击 **Add Package**。

**2. 导入模块**

```swift
import SwiftUIiOS26Showcase
```

**3. 开始使用**

将应用主文件（标有 `@main` 的文件，在新建的 Xcode 项目中名为 `<YourApp>App.swift`）的内容替换为：

```swift
import SwiftUI
import SwiftUIiOS26Showcase

@main
struct DemoApp: App {
    var body: some Scene {
        WindowGroup {
            ShowcaseGallery()
        }
    }
}
```

选择一个运行 iOS 26 的 iPhone 模拟器或 **My Mac** 作为运行目标，然后点击 **Run**（⌘R）。应用会打开一个按类别分组的演示列表，选择其中一个即可试用。如果 Xcode 提示该软件包需要更高的平台版本，请在 target 的 **General** 标签页中把 **Minimum Deployments** 设为 iOS 26 和 macOS 26。

## 安装

### Swift Package Manager

在 Xcode 中选择 **File › Add Package Dependencies…**，然后输入仓库地址：

```text
https://github.com/muhittincamdali/SwiftUI-iOS26-Showcase.git
```

或者将其添加到 `Package.swift` 的 `dependencies` 中：

```swift
dependencies: [
    .package(url: "https://github.com/muhittincamdali/SwiftUI-iOS26-Showcase.git", branch: "main")
],
targets: [
    .target(name: "YourApp", dependencies: [
        .product(name: "SwiftUIiOS26Showcase", package: "SwiftUI-iOS26-Showcase")
    ])
]
```

## 使用方法

### 显示完整的演示库

`ShowcaseGallery` 是一个导航栈，其中包含当前平台所有可用演示的可搜索列表。`ShowcaseGallery(initialDemo: .chart3D)` 会在界面出现时打开指定演示，例如处理深层链接时。

### 显示单个演示

`ShowcaseDemoView` 显示单个演示并设置其导航标题：

```swift
struct ChartScreen: View {
    var body: some View {
        NavigationStack {
            ShowcaseDemoView(.chart3D)
        }
    }
}
```

### 搜索目录

`ShowcaseCatalog` 包含演示库背后的列表、搜索和分组逻辑。当查询中的每个词都出现在某个演示的标题、摘要或 API 列表中时，该演示即为匹配项，匹配时忽略大小写和变音符号：

```swift
let catalog = ShowcaseCatalog(platform: .iOS)
let matches = catalog.demos(matching: "glass button")   // [.glassButtons]
let sections = catalog.sections(matching: "symbol")     // one section: Charts, Symbols & Animation
let demo = catalog.demo(withID: "webView")              // .webView
```

### 使用演示背后的辅助类型

部分演示背后的逻辑是公开的，并有测试覆盖：

```swift
// What the web view demo accepts in its address bar.
WebAddress.url(from: "swift.org")              // https://swift.org
WebAddress.url(from: "javascript:alert(1)")    // nil

// The heights plotted by the 3D chart, always in -1...1.
SurfaceFunction.peak.height(x: 0, z: 0)        // 1.0
```

`RichTextFormatter` 可以对 `AttributedString` 中选中的部分切换粗体、斜体、下划线和删除线，与富文本演示中的按钮效果相同。

### 个别演示的说明

- **Foundation Models** 需要 Apple Intelligence。在不支持它的设备上、它被关闭时，或模型仍在下载时，演示会说明属于哪种情况，并停用发送提示词的按钮。
- **标签栏附件**：`tabViewBottomAccessory(isEnabled:content:)` 需要 iOS 26.1。在 26.1 及更高版本上，演示会使用它；在 26.0 上，则通过添加或移除 `tabViewBottomAccessory(content:)` 来实现。
- **WebView** 出现时会加载 `https://www.swift.org` 这个地址，因此需要网络连接。地址栏只接受 `http` 和 `https` 地址。

### 运行示例应用

打开 `Examples/ShowcaseApp/ShowcaseApp.xcodeproj`，选择 `ShowcaseApp` scheme 以及一个 iOS 26 模拟器或 **My Mac**，然后点击 **Run**。该项目由 [XcodeGen](https://github.com/yonaskolb/XcodeGen) 根据 `project.yml` 创建，并通过本地路径使用本仓库中的软件包。

将 `-demo <id>` 作为启动参数传入即可直接打开某个演示，例如 `-demo glassEffect`。`scripts/screenshots.sh` 就是用这种方式截取 `docs/images` 中的图片。

## 架构

该软件包只有一个库 target：`SwiftUIiOS26Showcase`。

- `Catalog/`：`ShowcaseDemo` 为每个演示提供一个 case 及其元数据（标题、摘要、SF Symbol、类别、API、平台）。`ShowcaseCatalog` 负责按平台筛选、搜索、分组和查找演示。此文件夹中的代码不依赖任何 SwiftUI 视图。
- `Gallery/`：公开视图 `ShowcaseGallery` 和 `ShowcaseDemoView`。
- `Demos/<Category>/`：每个演示对应一个 internal 视图。不需要视图的逻辑放在公开的辅助类型中（`WebAddress`、`RichTextFormatter`、`SurfaceFunction`），以便测试覆盖。
- `Support/`：`DemoPage`，包含摘要、演示控件和 API 列表的共享布局。

演示元数据是演示库列表行、搜索和上方表格的唯一来源；如果 README 表格与元数据不一致，测试就会失败。测试在 macOS 上用 `swift test` 运行，在 iOS Simulator 中用 `xcodebuild test` 运行，CI 会运行这两者。
