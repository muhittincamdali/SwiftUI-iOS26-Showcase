SwiftUI iOS 26 Showcase — это Swift-пакет из шестнадцати небольших экранов на SwiftUI. Каждый экран
посвящён одной группе API, появившихся в iOS 26 и macOS 26: Liquid Glass, новые модификаторы панелей
и прокрутки, редактирование форматированного текста, встроенный веб-вью, 3D-графики, эффекты
прорисовки SF Symbols, макрос `@Animatable` и фреймворк Foundation Models, который работает прямо на
устройстве. На каждом экране есть элементы управления, чтобы попробовать параметры API, и список
символов SDK, которые он использует. Пакет предназначен для разработчиков, которые хотят увидеть эти
API в работе, прежде чем применять их у себя: можно запустить всю галерею или встроить один экран в
своё приложение.

## Основные возможности

- **16 демо в 6 категориях**: Liquid Glass, панели и навигация, прокрутка и вёрстка, текст и веб,
  графики и символы, Apple Intelligence. 14 из них работают и на macOS.
- **Галерея с поиском**: `ShowcaseGallery` показывает демо, доступные на текущей платформе, а поиск
  ищет совпадения в названиях, описаниях и именах API.
- **Один экран отдельно**: `ShowcaseDemoView(.chart3D)` встраивает одно демо в вашу собственную
  навигацию.
- **Тесты на macOS и в iOS Simulator**: наборы тестов на Swift Testing проверяют каталог,
  вспомогательные типы и то, что таблица демо ниже совпадает с кодом. Тест отрисовки проверяет,
  что каждое демо рисует больше, чем своё описание и список API, насколько это умеет
  `ImageRenderer`: два демо на основе `List` пропускаются, а в демо **WebView** тест видит адресную
  строку и строку состояния, но не саму `WebView`.
- **Пример приложения**: приложение для iOS и macOS в [Examples/ShowcaseApp](Examples/ShowcaseApp),
  которое открывает любое демо по аргументу запуска.

## Быстрый старт

**1. Добавьте пакет**

В Xcode выберите **File › Add Package Dependencies…** и введите адрес репозитория:

```text
https://github.com/muhittincamdali/SwiftUI-iOS26-Showcase.git
```

В том же окне оставьте для **Dependency Rule** значение по умолчанию, **Up to Next Major
Version**, начиная с `2.0.0` (более ранний релиз 1.0.0 вышел раньше этих демо). Нажмите
**Add Package**, выберите таргет своего приложения в столбце **Add to Target** и ещё раз нажмите
**Add Package**.

**2. Импортируйте модуль**

```swift
import SwiftUIiOS26Showcase
```

**3. Используйте**

Замените содержимое главного файла приложения (того, что помечен `@main`; в новом проекте Xcode он
называется `<YourApp>App.swift`) на:

```swift
import SwiftUI
import SwiftUIiOS26Showcase

@main
struct DemoApp: App {
    var body: some Scene {
        WindowGroup {
            ShowcaseGallery()
        }
    }
}
```

Выберите в качестве цели симулятор iPhone с iOS 26 или **My Mac** и нажмите **Run** (⌘R).
Приложение откроет список демо, сгруппированных по категориям; выберите любое, чтобы попробовать.
Если Xcode сообщит, что пакету нужна более новая платформа, установите **Minimum Deployments** на
iOS 26 и macOS 26 на вкладке **General** таргета.

## Установка

### Swift Package Manager

В Xcode выберите **File › Add Package Dependencies…** и введите адрес репозитория:

```text
https://github.com/muhittincamdali/SwiftUI-iOS26-Showcase.git
```

Или добавьте его в `dependencies` вашего `Package.swift`:

```swift
dependencies: [
    .package(url: "https://github.com/muhittincamdali/SwiftUI-iOS26-Showcase.git", branch: "main")
],
targets: [
    .target(name: "YourApp", dependencies: [
        .product(name: "SwiftUIiOS26Showcase", package: "SwiftUI-iOS26-Showcase")
    ])
]
```

## Использование

### Показать всю галерею

`ShowcaseGallery` — это навигационный стек со списком всех демо, доступных на текущей платформе, с
поиском. `ShowcaseGallery(initialDemo: .chart3D)` открывает демо при появлении экрана, например при
переходе по глубокой ссылке.

### Показать одно демо

`ShowcaseDemoView` показывает одно демо и задаёт его заголовок в навигации:

```swift
struct ChartScreen: View {
    var body: some View {
        NavigationStack {
            ShowcaseDemoView(.chart3D)
        }
    }
}
```

### Искать по каталогу

`ShowcaseCatalog` содержит логику списка, поиска и группировки, на которой построена галерея.
Запрос совпадает с демо, если каждое его слово встречается в названии, описании или списке API
демо; регистр и диакритические знаки не учитываются:

```swift
let catalog = ShowcaseCatalog(platform: .iOS)
let matches = catalog.demos(matching: "glass button")   // [.glassButtons]
let sections = catalog.sections(matching: "symbol")     // one section: Charts, Symbols & Animation
let demo = catalog.demo(withID: "webView")              // .webView
```

### Использовать вспомогательные типы демо

Логика некоторых демо открыта и покрыта тестами:

```swift
// What the web view demo accepts in its address bar.
WebAddress.url(from: "swift.org")              // https://swift.org
WebAddress.url(from: "javascript:alert(1)")    // nil

// The heights plotted by the 3D chart, always in -1...1.
SurfaceFunction.peak.height(x: 0, z: 0)        // 1.0
```

`RichTextFormatter` включает и выключает жирный, курсив, подчёркивание и зачёркивание для
выделенной части `AttributedString` — так же, как кнопки в демо форматированного текста.

### Замечания об отдельных демо

- **Foundation Models** требует Apple Intelligence. На устройстве без неё, когда она выключена или
  пока загружается модель, демо сообщает, какой из этих случаев имеет место, и отключает кнопку
  отправки промпта.
- **Аксессуар панели вкладок**: `tabViewBottomAccessory(isEnabled:content:)` требует iOS 26.1. В
  26.1 и новее демо использует этот API, а в 26.0 добавляет или убирает
  `tabViewBottomAccessory(content:)`.
- **WebView** при появлении загружает `https://www.swift.org` и поэтому требует подключения к сети.
  Адресная строка принимает только адреса `http` и `https`.

### Запустить пример приложения

Откройте `Examples/ShowcaseApp/ShowcaseApp.xcodeproj`, выберите схему `ShowcaseApp` и симулятор с
iOS 26 или **My Mac**, затем нажмите **Run**. Проект создан с помощью
[XcodeGen](https://github.com/yonaskolb/XcodeGen) из `project.yml` и подключает пакет из этого
репозитория по локальному пути.

Передайте `-demo <id>` как аргумент запуска, чтобы сразу открыть демо, например `-demo glassEffect`.
`scripts/screenshots.sh` использует это, чтобы снимать изображения в `docs/images`.

## Архитектура

В пакете один таргет библиотеки — `SwiftUIiOS26Showcase`:

- `Catalog/`: в `ShowcaseDemo` по одному case на каждое демо с его метаданными (название, описание,
  SF Symbol, категория, API, платформы). `ShowcaseCatalog` фильтрует по платформе, ищет,
  группирует и находит демо. Ничто в этой папке не зависит от представлений SwiftUI.
- `Gallery/`: публичные представления `ShowcaseGallery` и `ShowcaseDemoView`.
- `Demos/<Category>/`: по одному внутреннему представлению на демо. Логика, которой не нужно
  представление, вынесена в публичные вспомогательные типы (`WebAddress`, `RichTextFormatter`,
  `SurfaceFunction`), чтобы её можно было покрыть тестами.
- `Support/`: `DemoPage` — общий макет с описанием, элементами управления демо и списком API.

Метаданные демо — единственный источник для строк галереи, поиска и таблицы выше; если таблица в
README и метаданные расходятся, тест падает. Тесты запускаются командой `swift test` на macOS и
`xcodebuild test` в iOS Simulator; CI запускает оба варианта.
