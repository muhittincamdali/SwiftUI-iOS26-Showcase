SwiftUI iOS 26 Showcase는 작은 SwiftUI 화면 16개로 이루어진 Swift 패키지입니다. 각 화면은 iOS 26과
macOS 26에 새로 추가된 API 묶음 하나를 다룹니다. Liquid Glass, 새로운 바와 스크롤 모디파이어, 리치 텍스트
편집, 네이티브 웹 뷰, 3D 차트, SF Symbol 그리기 효과, `@Animatable` 매크로, 그리고 기기에서 실행되는
Foundation Models 프레임워크입니다. 모든 화면에는 API 옵션을 직접 바꿔 볼 수 있는 컨트롤이 있고, 화면에서
사용하는 SDK 심벌 목록이 표시됩니다. 자신의 앱에 적용하기 전에 이 API들이 실제로 동작하는 모습을 보고 싶은
개발자를 위한 패키지입니다. 갤러리 전체를 실행할 수도 있고, 화면 하나만 자신의 앱에 넣을 수도 있습니다.

## 주요 기능

- **6개 카테고리, 16개 데모**: Liquid Glass, 바와 내비게이션, 스크롤과 레이아웃, 텍스트와 웹, 차트와
  심벌, Apple Intelligence. 이 중 14개는 macOS에서도 실행됩니다.
- **검색 가능한 갤러리**: `ShowcaseGallery`는 현재 플랫폼에서 사용할 수 있는 데모를 나열하고, 제목과 요약,
  API 이름으로 검색할 수 있습니다.
- **화면 하나만 사용**: `ShowcaseDemoView(.chart3D)`로 데모 하나를 자신의 내비게이션에 넣을 수 있습니다.
- **macOS와 iOS Simulator에서 테스트**: Swift Testing 테스트 스위트가 카탈로그, 헬퍼 타입, 아래 데모 표가
  코드와 일치하는지를 확인합니다. 렌더링 테스트는 `ImageRenderer`가 그릴 수 있는 범위에서 각 데모가
  요약과 API 목록보다 많은 것을 그리는지 확인합니다. `List` 기반 데모 두 개는 건너뛰며, **WebView**
  데모에서는 주소 표시줄과 상태 표시줄은 확인하지만 `WebView` 자체는 확인하지 못합니다.
- **예제 앱**: [Examples/ShowcaseApp](Examples/ShowcaseApp)에 있는 iOS·macOS 앱으로, 실행 인자로 원하는
  데모를 열 수 있습니다.

## 빠른 시작

**1. 패키지 추가**

Xcode에서 **File › Add Package Dependencies…**를 선택하고 저장소 URL을 입력하세요.

```text
https://github.com/muhittincamdali/SwiftUI-iOS26-Showcase.git
```

같은 창에서 **Dependency Rule**은 기본값인 **Up to Next Major Version**으로 두고 `2.0.0`부터
시작하세요(이전 1.0.0 릴리스는 이 데모들보다 이전 버전입니다). **Add Package**를 클릭하고
**Add to Target** 열에서 앱 타깃을 고른 뒤 **Add Package**를 한 번 더 클릭하세요.

**2. 모듈 가져오기**

```swift
import SwiftUIiOS26Showcase
```

**3. 사용하기**

앱의 메인 파일(`@main`이 붙은 파일로, 새 Xcode 프로젝트에서는 이름이 `<YourApp>App.swift`입니다)의 내용을
다음 코드로 바꾸세요.

```swift
import SwiftUI
import SwiftUIiOS26Showcase

@main
struct DemoApp: App {
    var body: some Scene {
        WindowGroup {
            ShowcaseGallery()
        }
    }
}
```

실행 대상으로 iOS 26 iPhone 시뮬레이터나 **My Mac**을 고르고 **Run**(⌘R)을 누르세요. 카테고리별로 묶인
데모 목록이 열리면 하나를 골라 직접 사용해 보세요. 패키지에 더 새로운 플랫폼이 필요하다는 오류가 나오면
타깃의 **General** 탭에서 **Minimum Deployments**를 iOS 26과 macOS 26으로 설정하세요.

### Swift Package Manager

Xcode에서 **File › Add Package Dependencies…**를 선택하고 저장소 URL을 입력하세요.

```text
https://github.com/muhittincamdali/SwiftUI-iOS26-Showcase.git
```

또는 `Package.swift`의 `dependencies`에 추가하세요.

```swift
dependencies: [
    .package(url: "https://github.com/muhittincamdali/SwiftUI-iOS26-Showcase.git", branch: "main")

    .target(name: "YourApp", dependencies: [
        .product(name: "SwiftUIiOS26Showcase", package: "SwiftUI-iOS26-Showcase")
    ])
]
```

## 사용법

### 갤러리 전체 보여 주기

`ShowcaseGallery`는 현재 플랫폼에서 사용할 수 있는 모든 데모를 검색 가능한 목록으로 보여 주는 내비게이션
스택입니다. `ShowcaseGallery(initialDemo: .chart3D)`는 화면이 나타날 때 해당 데모를 엽니다. 딥 링크를
처리할 때 유용합니다.

### 데모 하나 보여 주기

`ShowcaseDemoView`는 데모 하나를 보여 주고 내비게이션 제목을 설정합니다.

```swift
struct ChartScreen: View {
    var body: some View {
        NavigationStack {
            ShowcaseDemoView(.chart3D)
        }
    }
}
```

### 카탈로그 검색하기

`ShowcaseCatalog`에는 갤러리의 목록, 검색, 그룹화 로직이 들어 있습니다. 검색어의 모든 단어가 데모의 제목,
요약, API 목록 중 어딘가에 들어 있으면 그 데모가 검색됩니다. 대소문자와 발음 구별 기호는 구분하지 않습니다.

```swift
let catalog = ShowcaseCatalog(platform: .iOS)
let matches = catalog.demos(matching: "glass button")   // [.glassButtons]
let sections = catalog.sections(matching: "symbol")     // one section: Charts, Symbols & Animation
let demo = catalog.demo(withID: "webView")              // .webView
```

### 데모 뒤에 있는 헬퍼 사용하기

일부 데모의 로직은 public으로 공개되어 있고 테스트로 검증됩니다.

```swift
// What the web view demo accepts in its address bar.
WebAddress.url(from: "swift.org")              // https://swift.org
WebAddress.url(from: "javascript:alert(1)")    // nil

// The heights plotted by the 3D chart, always in -1...1.
SurfaceFunction.peak.height(x: 0, z: 0)        // 1.0
```

`RichTextFormatter`는 `AttributedString`에서 선택한 부분의 굵게, 기울임꼴, 밑줄, 취소선을 켜고 끕니다. 리치
텍스트 데모의 버튼도 같은 방식으로 동작합니다.

### 개별 데모에 대한 참고 사항

- **Foundation Models**에는 Apple Intelligence가 필요합니다. 지원하지 않는 기기이거나 기능이 꺼져 있거나
  모델을 내려받는 중이면, 데모가 어느 경우인지 알려 주고 프롬프트를 보내는 버튼을 비활성화합니다.
- **탭 바 액세서리**: `tabViewBottomAccessory(isEnabled:content:)`에는 iOS 26.1이 필요합니다. 26.1 이상에서는
  데모가 이 API를 사용하고, 26.0에서는 `tabViewBottomAccessory(content:)`를 붙이거나 떼는 방식으로
  처리합니다.
- **WebView**는 화면이 나타날 때 `https://www.swift.org` 페이지를 불러오므로 네트워크 연결이 필요합니다.
  주소 표시줄에는 `http`와 `https` 주소만 입력할 수 있습니다.

## 요구 사항

| 플랫폼 | 최소 버전               |
| ------ | ----------------------- |
| iOS    | 26                      |
| macOS  | 26                      |
| 툴체인 | Swift 6.2 · Xcode 26.1+ |

탭 바 데모가 iOS 26.1 SDK의 API를 사용하므로 Xcode 26.0에서는 이 패키지를 빌드할 수 없습니다. Foundation
Models 데모에서 프롬프트를 보내려면 Apple Intelligence가 켜진 기기가 필요합니다.

## 아키텍처

이 패키지에는 라이브러리 타깃 `SwiftUIiOS26Showcase` 하나만 있습니다.

- `Catalog/`: `ShowcaseDemo`는 데모마다 case 하나와 메타데이터(제목, 요약, SF Symbol, 카테고리, API,
  플랫폼)를 가집니다. `ShowcaseCatalog`는 플랫폼별 필터링, 검색, 그룹화, 데모 조회를 맡습니다. 이 폴더의
  코드는 SwiftUI 뷰에 의존하지 않습니다.
- `Gallery/`: public 뷰인 `ShowcaseGallery`와 `ShowcaseDemoView`.
- `Demos/<Category>/`: 데모마다 internal 뷰 하나. 뷰가 필요 없는 로직은 테스트할 수 있도록 public 헬퍼
  타입(`WebAddress`, `RichTextFormatter`, `SurfaceFunction`)에 둡니다.
- `Support/`: `DemoPage`. 요약, 데모 컨트롤, API 목록을 담는 공통 레이아웃입니다.

데모 메타데이터는 갤러리 행, 검색, 위 표의 유일한 출처이며, README 표와 메타데이터가 다르면 테스트가
실패합니다. 테스트는 macOS에서 `swift test`로, iOS Simulator에서 `xcodebuild test`로 실행되며 CI는 둘 다
실행합니다.
