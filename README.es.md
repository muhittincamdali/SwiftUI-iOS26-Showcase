SwiftUI iOS 26 Showcase es un paquete de Swift con dieciséis pantallas pequeñas de SwiftUI, cada
una centrada en un grupo de API nuevas en iOS 26 y macOS 26: Liquid Glass, los nuevos
modificadores de barras y desplazamiento, la edición de texto enriquecido, la vista web nativa,
los gráficos 3D, los efectos de dibujo de SF Symbols, la macro `@Animatable` y el framework
Foundation Models, que se ejecuta en el dispositivo. Cada pantalla tiene controles para probar
las opciones de la API y muestra los símbolos del SDK que usa. Está pensado para desarrolladores
que quieren ver estas API funcionando antes de usarlas: puedes ejecutar la galería completa o
añadir una sola pantalla a tu propia app.

## Lo más destacado

- **16 demos en 6 categorías**: Liquid Glass, barras y navegación, desplazamiento y diseño,
  texto y web, gráficos y símbolos, y Apple Intelligence. 14 de ellas también funcionan en macOS.
- **Galería con búsqueda**: `ShowcaseGallery` muestra las demos disponibles en la plataforma
  actual, y la búsqueda encuentra coincidencias en títulos, resúmenes y nombres de API.
- **Una pantalla cada vez**: `ShowcaseDemoView(.chart3D)` coloca una sola demo dentro de tu
  propia navegación.
- **Probado en macOS y en el iOS Simulator**: las suites de Swift Testing comprueban el catálogo,
  los tipos auxiliares y que la tabla de demos de abajo coincida con el código. Una prueba de
  renderizado comprueba que cada demo dibuje más que su resumen y su lista de API, hasta donde
  `ImageRenderer` puede dibujarla: las dos demos basadas en `List` se omiten y, en la demo de
  **WebView**, la prueba ve las barras de dirección y de estado, pero no la `WebView` en sí.
- **App de ejemplo**: una app para iOS y macOS en [Examples/ShowcaseApp](Examples/ShowcaseApp)
  que puede abrir cualquier demo desde un argumento de lanzamiento.

## Inicio rápido

**1. Añade el paquete**

En Xcode, elige **File › Add Package Dependencies…** e introduce la URL del repositorio:

```text
https://github.com/muhittincamdali/SwiftUI-iOS26-Showcase.git
```

En ese mismo diálogo, deja **Dependency Rule** en su valor predeterminado, **Up to Next Major
Version**, a partir de `2.0.0` (la versión anterior, 1.0.0, es anterior a estas demos). Haz clic
en **Add Package**, elige el target de tu app en la columna **Add to Target** y vuelve a hacer
clic en **Add Package**.

**2. Importa el módulo**

```swift
import SwiftUIiOS26Showcase
```

**3. Úsalo**

Sustituye el contenido del archivo principal de tu app (el que lleva `@main`, que en un proyecto
nuevo de Xcode se llama `<YourApp>App.swift`) por:

```swift
import SwiftUI
import SwiftUIiOS26Showcase

@main
struct DemoApp: App {
    var body: some Scene {
        WindowGroup {
            ShowcaseGallery()
        }
    }
}
```

Elige como destino un simulador de iPhone con iOS 26 o **My Mac** y pulsa **Run** (⌘R). La app
abre una lista de demos agrupadas por categoría; elige una para probarla. Si Xcode indica que el
paquete necesita una plataforma más reciente, ajusta **Minimum Deployments** a iOS 26 y macOS 26
en la pestaña **General** del target.

## Instalación

### Swift Package Manager

En Xcode, elige **File › Add Package Dependencies…** e introduce la URL del repositorio:

```text
https://github.com/muhittincamdali/SwiftUI-iOS26-Showcase.git
```

O añádelo a las `dependencies` de tu `Package.swift`:

```swift
dependencies: [
    .package(url: "https://github.com/muhittincamdali/SwiftUI-iOS26-Showcase.git", branch: "main")
],
targets: [
    .target(name: "YourApp", dependencies: [
        .product(name: "SwiftUIiOS26Showcase", package: "SwiftUI-iOS26-Showcase")
    ])
]
```

## Uso

### Mostrar la galería completa

`ShowcaseGallery` es una pila de navegación con una lista, con búsqueda, de todas las demos
disponibles en la plataforma actual. `ShowcaseGallery(initialDemo: .chart3D)` abre una demo al
aparecer, por ejemplo desde un enlace profundo.

### Mostrar una sola demo

`ShowcaseDemoView` muestra una sola demo y fija su título de navegación:

```swift
struct ChartScreen: View {
    var body: some View {
        NavigationStack {
            ShowcaseDemoView(.chart3D)
        }
    }
}
```

### Buscar en el catálogo

`ShowcaseCatalog` contiene la lógica de lista, búsqueda y agrupación que hay detrás de la galería.
Una consulta coincide con una demo cuando cada una de sus palabras aparece en el título, el resumen
o la lista de API de la demo, sin distinguir mayúsculas, minúsculas ni signos diacríticos:

```swift
let catalog = ShowcaseCatalog(platform: .iOS)
let matches = catalog.demos(matching: "glass button")   // [.glassButtons]
let sections = catalog.sections(matching: "symbol")     // one section: Charts, Symbols & Animation
let demo = catalog.demo(withID: "webView")              // .webView
```

### Usar los tipos auxiliares de las demos

La lógica de algunas demos es pública y está cubierta por pruebas:

```swift
// What the web view demo accepts in its address bar.
WebAddress.url(from: "swift.org")              // https://swift.org
WebAddress.url(from: "javascript:alert(1)")    // nil

// The heights plotted by the 3D chart, always in -1...1.
SurfaceFunction.peak.height(x: 0, z: 0)        // 1.0
```

`RichTextFormatter` activa y desactiva la negrita, la cursiva, el subrayado y el tachado en la
parte seleccionada de un `AttributedString`, igual que los botones de la demo de texto enriquecido.

### Notas sobre algunas demos

- **Foundation Models** necesita Apple Intelligence. En un dispositivo que no la tiene, si está
  desactivada o mientras se descarga el modelo, la demo indica cuál de estos casos se da y
  desactiva el botón que envía el prompt.
- **Accesorio de la barra de pestañas**: `tabViewBottomAccessory(isEnabled:content:)` necesita
  iOS 26.1. En 26.1 y versiones posteriores la demo lo usa; en 26.0 añade o quita
  `tabViewBottomAccessory(content:)`.
- **WebView** carga `https://www.swift.org` al aparecer, así que necesita conexión a la red. La
  barra de direcciones solo acepta direcciones `http` y `https`.

### Ejecutar la app de ejemplo

Abre `Examples/ShowcaseApp/ShowcaseApp.xcodeproj`, elige el esquema `ShowcaseApp` y un simulador
con iOS 26 o **My Mac**, y pulsa **Run**. El proyecto se genera con
[XcodeGen](https://github.com/yonaskolb/XcodeGen) a partir de `project.yml` y usa el paquete de
este repositorio mediante una ruta local.

Pasa `-demo <id>` como argumento de lanzamiento para abrir una demo directamente, por ejemplo
`-demo glassEffect`. `scripts/screenshots.sh` lo usa para capturar las imágenes de `docs/images`.

## Arquitectura

El paquete tiene un único target de biblioteca, `SwiftUIiOS26Showcase`:

- `Catalog/`: `ShowcaseDemo` tiene un caso por demo con sus metadatos (título, resumen,
  SF Symbol, categoría, API y plataformas). `ShowcaseCatalog` filtra por plataforma, busca,
  agrupa y localiza demos. Nada en esta carpeta depende de vistas de SwiftUI.
- `Gallery/`: las vistas públicas, `ShowcaseGallery` y `ShowcaseDemoView`.
- `Demos/<Category>/`: una vista interna por demo. La lógica que no necesita una vista está en
  tipos auxiliares públicos (`WebAddress`, `RichTextFormatter`, `SurfaceFunction`) para que las
  pruebas puedan cubrirla.
- `Support/`: `DemoPage`, el diseño compartido con el resumen, los controles de la demo y la
  lista de API.

Los metadatos de las demos son la única fuente para las filas de la galería, la búsqueda y la
tabla de arriba; una prueba falla si la tabla del README y los metadatos no coinciden. Las pruebas
se ejecutan con `swift test` en macOS y con `xcodebuild test` en el iOS Simulator; CI ejecuta
ambas.
